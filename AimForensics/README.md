# AimForensics：從遊戲錄影分析瞄準行為（科展作品）

> 114 學年度新北市立北大高中校內科學作品展覽會　電腦與資訊學科 特優
> 三人小組作品；我擔任組長並負責模型訓練。

新型外掛改用獨立硬體與電腦視覺，從作業系統裡看不到。AimForensics 的想法是：不掃描記憶體或檔案，
只分析遊戲錄影中瞄準怎麼移動。人手會顫抖、有反應延遲、加減速是連續的；演算法控制的瞄準則太快、太穩、太規律。

## 執行方式

```bash
pip install -r requirements.txt
streamlit run app.py
```

開發環境：Python 3.11，Replit（底層 NixOS Linux）。

## 程式結構

| 部分 | 做什麼 |
|---|---|
| `CrosshairDetector`（app.py） | 準心偵測：中心法、邊緣法（Canny 邊緣偵測＋機率霍夫直線） |
| `screen_motion.py` | 用相鄰兩格的相位相關（`cv2.phaseCorrelate`）估計整個畫面的平移，累加成軌跡（v2 的預設方法） |
| `TrajectoryAnalyzer` | 速度、加速度、角速度（atan2）、抖動（原始座標減去高斯平滑後的殘差）、平滑度、方向改變次數；每 60 格切一段，整理成 10 維特徵 |
| `AnomalyDetector` | 黏著度、瞬間轉向、平滑度異常、方向熵四項指標加權成可疑度；可用邏輯迴歸（Z-score、L-BFGS）從標註資料學權重 |
| `SequenceModel` | Keras 模型：四層 Conv1D（批次正規化、最大池化、Dropout）＋兩層雙向 LSTM＋全連接層，Softmax 輸出兩類 |
| `AcademicVisualizer` | Plotly 圖表：軌跡、速度、角速度、速度分佈、特徵比較、訓練曲線 |
| `render_*`、`main` | Streamlit 介面：影片分析、模型訓練、權重學習、資料匯出、外觀五個頁籤 |

## 版本

- **v1（第一個 commit）**：科展時使用的版本。
- **v2（2026 年 10 月，AI 工具協助）**：新增 `screen_motion.py`，預設改用畫面位移當作軌跡；中心法與邊緣法保留作對照；修正抽樣時的時間步長。`python verify_screen_motion.py` 會產生兩支答案已知的測試影片並輸出 `verify_screen_motion.json`：

| | 畫面不動 | 每格右移 5 像素 |

## 目前的限制與下一步

- 畫面位移只描述整個畫面的平移；3D 旋轉、視差、移動中的角色、固定的 HUD、後座力與切換鏡頭都會干擾。
- 規則層把「完全不動、太平滑」也視為異常，靜止畫面的可疑度偏高；可疑度是規則分數，不是校準過的機率。
- 時序模型目前以每段的特徵向量訓練，還沒有接入分析流程；下一步改成輸入逐格特徵序列。
- 需要更多真實遊戲影片，並依影片切分訓練、驗證、測試資料來評估。

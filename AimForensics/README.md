# AimForensics：從遊戲錄影分析瞄準行為（科展作品）

> 114 學年度新北市立北大高中校內科學作品展覽會　電腦與資訊學科 特優
> 三人小組作品；我擔任組長並負責模型訓練。
> `app.py` 是科展時使用的程式（檔頭日期 2026 年 1 月），沒有修改過。2026 年 10 月重新檢查後找到的問題列在下面。

新型外掛改用獨立硬體與電腦視覺，從作業系統裡看不到。AimForensics 的想法是：不掃描記憶體或檔案，
只分析遊戲錄影中瞄準怎麼移動。人手會顫抖、有反應延遲、加減速是連續的；演算法控制的瞄準則太快、太穩、太規律。

## 執行方式

```bash
pip install -r requirements.txt
streamlit run app.py
```

開發環境：Python 3.11，Replit（底層 NixOS Linux）。

## 程式結構（全部在 `app.py`，共 4,055 行）

| 部分 | 行號 | 做什麼 |
|---|---|---|
| `CrosshairDetector` | 535–713 | 取得每一格的準心位置：中心法直接回傳畫面中心；邊緣法在畫面中央區域用 Canny 邊緣偵測＋機率霍夫直線找十字線 |
| `TrajectoryAnalyzer` | 721–1091 | 由位置差分算速度、加速度；用 atan2 算角速度；抖動（原始座標減去高斯平滑後的殘差）、平滑度、方向改變次數；每 60 格切一段（重疊 30 格），每段整理成 10 維特徵向量 |
| `AnomalyDetector` | 1099–1762 | 黏著度、瞬間轉向（Snap）、平滑度異常、方向熵四項指標加權成可疑度；`train_logistic_regression` 用邏輯迴歸（Z-score 標準化、L-BFGS）從標註資料學權重 |
| `SequenceModel` | 1770–1861 | Keras 模型：四層 Conv1D（批次正規化、最大池化、Dropout）＋兩層雙向 LSTM＋全連接層，Softmax 輸出兩類 |
| `AcademicVisualizer` | 1869–2226 | Plotly 圖表：軌跡、速度、角速度、速度分佈、特徵比較、訓練曲線 |
| `render_*` 與 `main` | 2413–4055 | Streamlit 介面：影片分析、模型訓練、權重學習、資料匯出、外觀五個頁籤 |

## 已知問題（2026 年 10 月重新檢查）

重新檢查時使用了 AI 工具協助逐行閱讀，並用一支畫面會平移、準心固定在中央的測試影片重跑規則層。

1. **量錯了東西。** FPS 遊戲的準心固定在畫面中央，真正會動的是畫面。中心法每一格都回傳畫面中心（第 574–582 行），軌跡只有一個點，所以在預設靈敏度 0.5 下，不論輸入哪部影片，可疑度都是 0.75、判為 `likely_cheating`（常數軌跡的可疑度是 0.6×(1+靈敏度/2)，靈敏度調到多少都判為作弊）。邊緣法取的是中央區域所有直線的平均位置，量到的多半是背景線條。
2. **時序模型沒有時序，也沒有接上分析流程。** 訓練時每一段只是一個 10 維向量，`sequence_length=1`（第 3100 行）；照 Keras 的輸出長度公式，長度 1 經過 `pool_size=2` 的最大池化會變成 0。訓練好的模型（`predict()`／`predict_single()`）也沒有被任何頁籤或分析流程呼叫，分析結果全部來自規則層。
3. **「信心指數」不是外掛機率。** `classify_behavior`（第 1740–1762 行）回傳的是對判定類別的信心：可疑度 0.05 的影片會顯示 95%；可疑度跨過 0.3 和 0.6 時數字會往下跳。「切片長度敏感度測試」卻把這個數字畫在 70% 的外掛門檻線上比較。
4. **結果無法重現。** 這個版本只要算得出結果，信心指數最低就是 0.5，但科展報告表 1 有 0.42、0.48。科展報告中的訓練資料（60 部影片、432 個片段）與測試結果，我無法用這份程式重現，所以這裡不列出。程式第 2232 行的 `_generate_mock_training_data()` 會產生 60 筆示範影片紀錄（`human_gameplay_01–30`、`aimbot_sample_01–30`），數量和報告相同，目前沒有被呼叫；權重學習頁的「Generate Synthetic Data」（第 3314–3361 行）會用常態／指數分佈產生合成樣本。我無法確定報告的數字是否來自真實影片，所以不引用。這兩段程式保留在原版中，下一版會把示範資料和真實資料清楚分開標示。

科展報告與程式不一致的地方：

| 項目 | 科展報告 | `app.py` |
|---|---|---|
| 邊緣法 | Canny＋形態學運算 | Canny＋機率霍夫直線（第 613–617 行） |
| 抖動的高斯平滑 | σ = 3 | σ = 5/3 ≈ 1.67（第 874–875 行） |
| 方向熵 | 8 個方向區間 | 角速度大小分成 20 個區間（第 1362–1363 行） |
| 頻譜 | Welch 功率頻譜 | 有寫 `compute_frequency_spectrum`，但沒有被呼叫 |

## 修正計畫

1. 改量畫面的位移：用相鄰兩格的相位相關（`cv2.phaseCorrelate`）或光流估計整個畫面平移，累加成瞄準軌跡；先用答案已知的影片檢查（畫面完全不動、等速平移）。
2. 模型改吃真正的序列：每段輸入 60 格的逐格特徵（形狀 60×k），拿掉會把長度壓到 0 的池化，並把模型輸出接回分析頁。
3. 一律輸出可疑度或邏輯迴歸算出的外掛機率，類別另外顯示。
4. 依影片（不是依片段）切出訓練、驗證、測試三份資料；在看到測試集之前固定門檻；用 Git 記錄每次實驗的程式版本、資料清單與設定。
